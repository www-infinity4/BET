# BET

A synchronized Infinity TV Network channel centered on high-quality Black entertainment, sports, music and culture.

## Programming standard

- Full classic NBA games when an authorized full-game source is available.
- Championship boxing and complete fights from official rights-holder channels.
- Long-form BET music/performance programming and culture coverage.
- Premium films such as *Space Jam* only when a legitimate full-length playback source is available.
- No trailers, one-minute promos, or short clips presented as full programming.
- New deterministic daily lineup at the viewer's local midnight.
